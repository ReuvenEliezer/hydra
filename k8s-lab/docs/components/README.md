# Component pages

One page per major component. Each answers the same eight questions (FR-111,
SC-021):

1. What it is
2. Why it exists here
3. What problem it solves
4. How it works
5. How to inspect it
6. **How to break it**
7. **How to recover it**
8. Its production equivalent

Questions 6 and 7 are the ones worth having. A component you have never broken
is a component you do not understand, and the recovery step is what turns an
outage into a procedure.
